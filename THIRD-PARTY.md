# Third-party components

## jsnes 2.1.0 — Apache-2.0

`vendor/jsnes.min.js` is jsnes 2.1.0, distributed **unmodified**
(https://github.com/bfirsh/jsnes). Full license text: `vendor/LICENSE-jsnes.txt`.

`engine.js` is original code by this project; it links against jsnes at runtime
through the browser global `window.jsnes`.

## Built-in game demo — 星光试航 / Star Pilot

`games/starpilot.nes` is an original NES demo generated by the author's own
`make_demo.py` (repository `zeelinkCN/game-bench-macos`, `Resources/Demo/`).
It may be redistributed with this MIT plugin.

## Game market content

The in-panel game market reads a separate, private resource repository
(`zeelinkCN/game-bench-library`): catalog metadata, cover images and ROM files.
Those assets are **not** part of this repository and are not covered by the MIT
license; they are used under the repository owner's authorization.
